# 数据不足时如何收束结论

## 适用问题

- 关键指标返回 unknown，这个问题还答不答得了？
- 数据缺一个周期，是继续换口径查，还是直接说查不到？
- 什么情况下"我不知道"是合格交付，什么情况下是偷懒？

## 怎么理解

数据不足不是一个状态，而是**四种不同的限制**，各自允许的结论不同。把它们统一说成"数据缺失"，就会同时犯两种错：把可查的当成查不到而提前收束，和把查不到的编成结论。

### 四类限制

1. **范围不足**：对象或周期没覆盖到问题问的范围（缺周期、选了不可比的集合）。限制的是"这个结论适用于谁、适用于哪段时间"。
2. **字段不存在**：问题要的证据在当前数据域根本没有（素材数量、券与核销条件、库存、内容质量、竞对价格）。限制的是"这个问题在当前系统里不可答"。
3. **值不可用**：字段存在但该对象该周期没有值或分母为零，返回 unknown 并附原因码。限制的是"这个指标这一次不能用"，不是"这个商品是 0"。
4. **记录相互冲突**：同一对象同一周期存在多条互相矛盾的记录，或对象身份跨期不一致，比较被直接阻断。限制的是"任何基于这些记录的变化结论"。

### unknown 的四种原因码

`period_missing`（该对象该周期无记录）、`field_missing`（字段缺失或整列为空）、`zero_denominator`（比率类指标分母为零）、`window_incomparable`（两期窗口不可比）。**原因码必须原样转述**，因为它们指向不同的下一步：前两种可能要换对象或换周期再看，第三种要改看合计层指标，第四种要先解决可比性。

统一的处理底线：unknown 不静默代 0，不回退成简单平均，不与其他周期的值拼接。

### 收束的正确形态是分层交付，不是二选一

数据不足不等于只能回答"不知道"。合格交付是把答案分成四层：

- **已证事实**：这一轮真实查到、可回指证据的数值与状态；
- **工具已确定的边界**：窗口、比较范围、unknown 原因与阻断状态按当前工具响应说明，不从知识文档另造确定值；
- **候选因素与未证解释**：值得查但当前没有证据支持的方向，明确标为假设；
- **处理边界与完成状态**：哪些没查、为什么没查、下一次要什么证据才能推进。

### 什么时候必须补查，什么时候必须停

必须补查（不能直接收束）：

- 结论需要"变化"，但只拿到了单期值；
- 结论需要"是不是普遍"，但只查了单个对象，没查集合；
- 结论需要"哪一层在变"，但只看了结果层（订单量），没看流量与效率层；
- 出现了 unknown 或冲突状态，但还没读原因码。

必须停止（不能继续推）：

- 所需字段在数据域根本不存在 → 报边界，不换口径硬凑；
- 身份不一致或记录冲突阻断了比较 → 不择一条记录继续算；
- 查询预算耗尽 → 按预算终止的状态交付已有证据，不重开同一条查询绕过；
- 补查只会重复已经排除的方向。

## 常见情况

- 问"这个商品最近怎么样"，只有一期有值 → 报单期事实与"另一期缺哪条"，不给趋势；
- 问"是不是所有商品都在跌" → 必须先做集合比较，只有个体证据时不能升格为普遍判断；
- 问"为什么掉量" → 各层分别核对后才能说哪一层在变；机制层证据（素材、分发资格判定、券、库存）多数不可查，只能进候选因素；
- 问"核销率/退款/毛利" → 字段不存在，属于第二类限制，直答不可答并说明需要什么数据。

## 建议继续看什么证据

- 每个指标块的原因字段：`state`、`unknown_reason`、`value_detail`、`excluded_missing`、`excluded_conflicting`；
- 集合比较的缺失组：哪些对象因为什么原因没进比较；
- `states`：对象身份、周期状态字段跨期是否一致；
- 取证结果：对单个周期的关键数值做同源核对，确认缺失是"没有"还是"没查到"；
- 预算读数：本轮剩余查询额度；预算耗尽属于处理边界，要如实写进交付。

## 可考虑的经营方向

- 范围不足 → 换更小的问题继续（先确定能答哪一部分），而不是整体放弃；
- 字段不存在 → 把该方向留在候选因素，并说明它在当前系统内不可验证；
- 值不可用 → 用同层的合计类指标补一次方向判断，并说明替代口径；
- 记录冲突 → 先修数据口径，冲突未解前不给任何变化结论。

## 不能支持的判断

- 不能把 unknown 写成 0、写成"没有表现"、写成"表现差"；
- 不能用"数据不足"为不查可查项背书；
- 不能把候选因素写成原因（没有机制证据时保持条件化表述）；
- 不能用多条互相冲突的记录分别支撑两个结论，装作一致；
- 不承诺补查后一定可以得到答案——补查的判据是"这条证据存在且可查"。
