# 商品生命周期经营

## 适用问题

- 新品刚开始跑，应该先看什么？
- 一个商品刚测试两轮、没起量，要不要马上放弃？
- 已经稳定有动销的商品，后面的关注点和新品有什么不同？
- 一个原来表现不错的商品开始衰退，应该怎么排查？

## 怎么理解

商品生命周期经营的核心，不是给商品贴一个"好 / 坏"标签，而是先回答一个问题：**这个商品目前获得了多少测试机会、形成了什么信号**。同样一个结果——比如"没有订单"——在刚上线的商品和已经充分测试过的商品上，含义完全不同。

商品经营可按“小批量测试 → 数据回收 → 追投、补量或降低优先级”循环推进。以下四个阶段按测试机会与已形成的信号区分。

## 常见情况

### 初始测试 / 冷启动阶段

这个阶段的核心问题不是"商品好不好"，而是**有没有获得基本测试机会**：

- 有没有足够的内容供给（有没有人发、发得够不够）；
- 有没有基础流量反馈（内容发出去后有没有获得播放）；
- 有没有初步交易信号（哪怕零星动销也是信号）；
- 基础承接条件是否受限，如价格吸引力、素材、门店与库存。

常见误判是：早期没有动销就直接淘汰。早期没有动销，可能是商品不适合，也可能只是测试不足——这两种解释对应完全不同的动作，只有先确认测试机会给够了，才轮到判断商品本身。

### 观察阶段

商品已经获得部分曝光或投稿后，关注点从"有没有机会"转向"信号质量"：

- 流量是否还在继续扩大；
- 转化效率（如 OPM / GPM）有没有出现信号；
- 新增内容是否还带来增量（加了供给之后，播放和订单有没有响应）；
- 是否开始出现稳定动销。

观察阶段最容易混淆的是两种状态：**量不足导致没验证出来**，和**已经获得足够机会但仍无有效信号**。前者的结论是"测试还不充分"，后者的结论才是"商品当前缺乏有效信号"。区分的依据是测试机会的证据，不是感觉。

### 稳定动销阶段

商品已经有稳定动销后，关注点转为放大的质量：

- 是否值得继续扩大内容供给；
- 扩量之后效率有没有明显下降（边际收益是否在稀释）；
- 承接条件是否还跟得上规模。

常见误判是把"还在动销"直接当作"可以无限放大"。扩大的前提是效率与承接都还撑得住，而不是动销本身。

### 衰退阶段

原来表现不错的商品开始下滑时，优先做的不是找原因下结论，而是**区分哪一层在降**：

- 内容供给下降（发布少了）；
- 流量下降（播放收缩）；
- 转化效率下降（有播放但订单效率走弱）；
- 价格或承接条件变化；
- 商品本身热度衰退。

不能只因为订单下降就直接判断"素材质量变差"。订单下降是结果，供给、流量、转化、承接任何一层变化都可能造成这个结果，需要逐层核对证据。

## 建议继续看什么证据

- 两期对比（diff）：M1 订单量、M2 播放量、M4 OPM、M5 GPM 的方向与幅度，先分清"规模层"和"效率层"哪个在变；
- 集合比较（set_compare）：商品在目录池中的排名或与中位数的距离，判断相对位置；
- 发布状态（states 可查 published）：当期是否还有新增视频发布；注意没有新增发布时旧视频仍可能带来流量，不能把播放全部归因于当期投稿；
- 当前标价可作静态背景，但同一商品跨期恒定；投稿条数、素材、库存、券、门店承接及平台分发机制不可查，相关变化只能列为待验证假设。

## 可考虑的经营方向

- 测试机会明显不足 → 先补足基础测试，观察基础流量与交易反馈，而不是下商品结论；
- 观察期有效率信号但规模小 → 更值得验证曝光与供给约束，确认"有没有被看见"；
- 稳定动销期 → 扩大供给前先核对效率趋势与承接条件，扩量后持续观察效率是否稀释；
- 衰退期 → 先定位是哪一层在降（供给 / 流量 / 转化 / 承接），再选择对应动作；不同层对应不同动作，不能一概而论。

## 分析边界

- 不存在"第 X 天必须追投 / 汰换"这类时间表；是否追投或汰换取决于测试机会与信号证据；
- 模拟周期与日期窗口只支撑已覆盖范围内的判断；不能据此推断真实平台的季节性、行业周期或窗口外趋势。
