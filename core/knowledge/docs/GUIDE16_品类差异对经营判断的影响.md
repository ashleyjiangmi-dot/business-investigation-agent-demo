# 品类差异对经营判断的影响

## 适用问题

- 奶茶和西快的数据能放在同一把尺子下比吗？
- 为什么火锅类商品的 GPM 天然比饮品高？
- 同一指标在不同品类里"算好"的标准一样吗？
- 哪些品类更适合用批量内容去做冷启动？

## 怎么理解

品类通过三条路径改变经营读数：**客单价量级、决策门槛与频次、履约形态**。跨品类直接比绝对值，多半比的是品类属性而不是经营质量。

### 路径一：客单价量级决定率类指标的可比性

成交额类指标（GPM）等于"每千次播放折算的成交规模"，它的分子里带着价格。设想两个模拟品类的成交单价分别为 20 元与 100 元，订单和播放相同，后者的成交额效率会更高。**同样的播放与订单，价格高的品类 GPM 天然更高**，跨品类比 GPM 没有含义。

订单效率类指标（OPM）不含价格，跨品类可比性稍好，但仍受决策门槛影响。

### 路径二：决策门槛与频次决定"多少播放能换来一单"

高频低价、低决策门槛的品类（奶茶饮品、西式快餐、小食）用户看到即下单的概率更高，可优先验证这类品类的批量内容可生产性；低频高客单（火锅正餐、礼盒、需到店的套餐）需要更强的种草与更长的决策链，短期 OPM 低不必然代表内容无效。

### 路径三：履约形态决定"付了钱之后还要不要跑一趟"，不决定订单多少

本域的交易读数是**支付订单**：用户付款即计入，与之后是否到店核销无关。所以"履约链长"**不能**用来解释某个品类订单少——核销早晚不改变支付订单落在哪个周期。履约形态真正改变的是两件事：一是**决策链**（要不要到店、能不能约上、券怎么用最划算），它会推迟付款本身；二是**可售门槛**（限门店、限时段、限配送范围、短保质期），它会直接挡掉一部分用户的下单。这两条才是品类间可比性的实际破坏者，且在本域都无字段可证（详细例外见 GUIDE17）。

### 哪些品类更适合批量内容冷启动

批量冷启动可优先考虑：标准化程度高、素材稳定、优惠信息清晰、用户认知成本低的高频低价品类（西快、奶茶）先做；到综类（商超、电动车、汽车服务、丽人）在内容识别与形态上与传统探店差别大，需要单独判断。这条经验的适用条件是"用低成本内容扫量"，不是"这些品类更有价值"。

## 常见情况

- 跨品类比 M4/M5 绝对值 → 先按品类分组再比，或改成与该商品自身两期比；
- 高客单品类播放好但订单少 → 先看决策门槛与可售门槛（要不要到店、限不限门店/时段），再谈承接（GUIDE05、GUIDE17）；不要用"核销慢"解释订单少；
- 低客单品类订单多但 GPM 低 → 属正常量级差异，不是效率恶化；
- 礼盒/组合套餐类商品 → 单价含多件与非餐饮实物，不能当单品价格用（GUIDE12）；
- 品类内跨品牌价差 → 同规格对齐后再比（GUIDE12）。

## 建议继续看什么证据

- 对象身份信息：类目、城市、标价（`catalog` 与对象信息可查），决定这次比较是否同类；
- 同类对象集合：把集合比较的对象显式限定在同一品类内（GUIDE13）；
- 该商品自身两期变化（`op=diff`），在没有同类样本时优于跨品类比较；
- 行业人均、市场规模等公开资料量级：可用于说明品类属性，**不可当作本 Demo 的经营数据或行业基准**；
- 频次、复购、决策链路长度：当前数据域没有对应字段，只能作为品类属性层面的背景理解。

## 可考虑的经营方向

- 报告相对表现时先说明"在哪个品类集合内"；
- 判断"值不值得继续投"时，把品类量级与决策门槛作为前提写出来；
- 冷启动资源优先给内容可生产性与标准化程度高的品类，但结论仍须回到单个商品的证据（GUIDE09）。

## 不能支持的判断

- 不能说"某品类表现差"，实际是量级口径不同；
- 不能引用公开人均/客单数据作为本 Demo 商品的价格或经营读数；
- 不能用品类偏好替代单商品证据；
- 不承诺某类内容形态在某品类一定有效。
