# 冷启动与测试充分性判断

## 适用问题

- 一个新商品跑了两个周期还没有订单，现在能说它不行吗？
- 冷启动阶段到底要观察到什么，才算"给过机会"？
- 一个商品一直没动销，是"测过了没信号"还是"根本没测到"？
- 冷启动期看到"出坡""未出坡"这类标记，能直接当结论用吗？

## 怎么理解

冷启动要回答的不是"这个商品好不好"，而是**"我们已经拿到了多少关于它的信息"**。同一个"零订单"，在两种处境下含义相反：一种是还没形成有效机会，结论只能是继续测；另一种是机会给足了仍然没有信号，结论才可以转向降低优先级。

机会是否形成，看三层，缺一不可：

### 第一层：供给是否持续

商品在这段时间里是否还有新增内容发布。判断的是"动作有没有在做"，不是做了多少条。发布中断与发布持续但量小，是两个不同的状态；前者是经营动作缺位，后者才轮到看分发与效率。

### 第二层：供给有没有换来分发与播放

发了不等于被看见。内容要经过识别、进入可分发状态、再获得曝光，中间每一级都有折损。所以冷启动阶段的关键观察是：**供给与流量反馈是否相称**——有新增发布却几乎没有播放，要解释的是"为什么没分发"，而不是"商品不行"。

需要注意，这一层的机制细节当前没有数据：可查的只有周期汇总的播放量方向，以及行级是否存在有效 POI、是否公开等资格标记，看不到"这条视频卡在哪一关"。

### 第三层：窗口是否够长

分发自带滞后。进入分发与反馈稳定是不同阶段，需要分别观察，不宜设置统一天数门槛。**只要实际观察窗口短于内容形成稳态所需时间，"没有信号"就不能读成"没有潜力"。**

## 常见情况

- **刚上线两期、有发布、播放很低**：优先解释是分发与曝光机会不足，而不是商品吸引力不足；此时任何"汰换"结论都缺前提。
- **两期都没有新增发布**：属于经营动作没做，测试根本没开始，谈不上结果。
- **发布正常、播放正常、始终没有订单**：三层里前两层成立，问题才开始指向商品与承接（见 GUIDE05）。
- **有零星订单但没有连续性**：这是"初步信号"，与"稳定动销"不同，仍属于观察阶段，不适合直接放大。
- **同一商品在不同周期里冷启动标记不同**：冷启动是行级演示字段，用来说明这批内容有多新，它不进 M1–M5 口径，不能拿来当判定依据。

## 建议继续看什么证据

- `states`：各周期是否还有新增发布（`published`），判断供给是否持续；
- `op=value` + `op=diff`（M2 播放量）：投放之后流量反馈有没有跟上，两期方向如何；
- `op=value`（M1 订单量）与 M4/M5：有没有形成任何交易信号，注意 unknown 附原因码，不等于零；
- 窗口本身：核对工具返回的起止日期、时间粒度与覆盖范围，不能把有限模拟窗口外推为真实长期趋势；
- 投稿条数、素材库存、内容质量、分发资格判定明细、核销时间：**当前数据域没有对应字段**，涉及这些方向时只能作为待验证假设列出。

## 可考虑的经营方向

- 三层任一不成立 → 结论只能是"测试尚未完成"，动作是补足机会并设观察点，不是判商品；
- 三层都成立且无信号 → 才进入"降低继续投入优先级"的讨论（判据见 GUIDE07、GUIDE14）；
- 三层成立且有效率信号 → 转向放大前的效率与承接核对（GUIDE01、GUIDE03）；
- 窗口明显短于分发滞后 → 优先延长观察而不是加动作。

## 分析边界

- **不设统一的条数、百分比或天数门槛**；测试充分性须有供给、流量与观察窗口三层证据；
- 两期无订单不能直接证明商品无潜力；三层机会已经给足时，也不能无限延长观察；
- 冷启动演示字段（如出坡标记）不参与 M1–M5 计算，不能代替测试充分性判断。
