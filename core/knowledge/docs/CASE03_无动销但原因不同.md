# 无动销但原因不同

## 背景

这是一个用于说明分析方法的合成案例（synthetic case），不对应任何真实线上商品或真实运行数据。

场景设定：商品池里有两个商品，最近一个周期都没有明显动销。单看"没有订单"这一个结果，它们长得一模一样；但两者的历史处境完全不同：

- **商品 A**：新进入测试，内容供给仍不足，还没有获得充分的流量机会；
- **商品 B**：已经历多轮测试，内容供给已经较充分，仍然缺少有效交易信号。

## 观察到什么

两个商品相同的结果：当期没有明显动销。

两个商品不同的处境：

- 商品 A：新增发布少、播放量低、处于测试早期；
- 商品 B：发布节奏正常、播放机会已给到、此前多轮测试也没有形成稳定交易信号。

（以上均为相对描述，本案例不使用也不虚构具体数值。）

## 可能解释

"没有动销"只是一个结果，不是原因。两个商品的可能解释完全不同：

- 商品 A：更可能只是**尚未完成验证**——测试机会还没给够，当前结果不足以对商品本身下任何结论；
- 商品 B：更可能是**已经获得机会但没有形成有效信号**——测试充分性基本满足，商品吸引力、价格或承接环节存在问题。

## 如何继续区分

区分的关键变量是**测试机会是否充分**，通常按以下顺序核对：

1. 供给节奏：当期是否还在新增发布，历史供给够不够；
2. 流量反馈：播放量是否获得了与供给匹配的机会，有没有"发了但没分发"的迹象；
3. 时间与窗口：两期窗口是否可比、测试是否跨过足够的观察期；
4. 承接条件：有没有价格等商品属性的明显异常（有异常先修承接，它会污染一切测试结论）；券、库存、POI 当前数据域无对应字段，查不到，只能列为待验证假设并如实说明。

核对后的动作分叉：

- **商品 A：当前更像"尚未完成验证"，适合继续完成基础测试**——补足供给与流量机会，设观察点，等信号；
- **商品 B：当前更像"已经获得机会但没有形成有效信号"，应降低继续重复供给的优先级**，转向商品、价格、承接问题检查；继续堆同类内容边际价值低。

必须说明：以上判断依赖"测试机会充分性"的证据。如果 A 实际上已经获得过充分流量机会，它就不再是 A 形态；如果 B 的"充分测试"证据不足，也不能急着降级。

## 得到什么经验

**相同结果（无动销）在不同测试处境下对应完全不同的经营解释与动作。**

是否获得充分测试机会，决定了"没有动销"读作"还没验证"还是"验证后无信号"。前者结论是继续测试，后者结论才是降低优先级并转向商品与承接调查。把两个商品混在同一个"没订单所以不行"的判断里，会同时犯两类错误：错杀测试不足的商品，和拖延处理真正没有信号的商品。

## 不能类比的条件

- 商品 A 实际已有充分流量机会仍无信号：它已经不是 A 形态，按 B 形态处理；
- 商品 B 的测试充分性证据不足：先补证据再谈降级，"感觉测够了"不构成证据；
- 任一商品存在明确的承接异常：可查的那类（如价格异常）先修承接再谈测试与汰换，否则测试结论被污染；券不可用等当前数据域无对应字段、查不到，只能列为待验证假设；
- 两期窗口不可比或关键数据缺失：先处理可比性与数据问题，阶段判断悬置。
