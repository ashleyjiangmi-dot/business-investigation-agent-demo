# 商品潜力判断

## 适用问题

- 数据暂时一般，这个商品还有没有培养价值？
- 一个商品订单不高，但转化效率不错，还值得继续给内容吗？
- 订单量一直不温不火，但转化效率不错、历史也有动销的商品，还值不值得继续培养？
- 一个热度很高的商品，为什么不一定适合 AIGC 扩量？
- 怎么区分"潜力品"和"只是暂时有流量"？

## 怎么理解

商品潜力不是单指标判断。订单量是结果指标，受内容供给、流量规模、转化效率、承接条件多层影响，单看一个周期的一次结果，无法回答"值不值得继续投入"。

**商品潜力是是否值得继续投入测试或扩大供给的综合判断**，不等同于当前订单排名。判断时综合以下六类信号，并说明证据缺口。

### 六类信号

1. **交易信号**：有没有历史动销、近期订单、稳定转化，而不是只看一次峰值。可以把商品按"一直无动销 / 历史有动销 / 持续有动销"拆开处理，就是因为交易信号的历史形态直接改变判断。
2. **流量与效率信号**：要分清是"没流量所以没订单"，还是"流量已经有了但转化弱"。前者缺的是测试与曝光，后者缺的是吸引力或承接——两种形态指向完全不同的下一步。
3. **内容供给缺口**：商品表现一般，是否因为现有内容不足。如果已经有充分供给仍无信号，解释就完全不同了。
4. **价格与商品吸引力**：有价格优势可以降低测试成本（需用同规格、同条件的外部价格核对）；但"不是最低价"不等于没有潜力，价格只是降低验证门槛的因素之一。
5. **素材与内容可生产性**：有没有足够的真实素材、商品特写、门店 / 使用场景，决定了 AIGC 内容供给能不能持续做出来。这一条对 AIGC 供给模式尤其关键：真实素材是信任的底座，素材条件差的商品即使有热度，也难以用这套模式持续扩量。
6. **本地生活承接条件**：POI、库存、券等现实承接条件，决定"有内容潜力"能不能最终变成交易。

### 两个经营视角

- **爆品 / 热品**：目标偏向放大已有热度，重点看流量与交易效率是否持续、供给是否跟得上；
- **长尾 / 低供给商品**：目标偏向用低成本内容测试能否激活动销，重点看测试是否充分、有没有初步信号。

商品池可以分成爆品货盘与长尾货盘，两类的目的不同（放大已有热度 vs 激活存量价值），判断标准自然也不同。拿同一把尺子量两类商品，是潜力判断里最常见的错误。

## 常见情况

- **数据一般，但有历史动销**：先核对供给节奏、流量与效率；价格变化需要跨期价格证据，不能直接假定为原因。
- **新品效率不错但没规模**：效率信号（OPM / GPM）尚可说明"每次曝光的质量"还可以，规模不足更像曝光与供给问题，通常值得先验证供给约束。
- **热度高但素材条件差**：热度本身不是问题，AIGC 扩量卡在可生产性——没有真实素材支撑，内容供给模式转不起来。这类商品"不适合 AIGC 扩量"不等于"没有商业价值"。
- **只是暂时有流量**：流量有可能是短期分发波动带来的，判断它是不是"潜力"，要看流量背后有没有转化信号和持续供给支撑，而不是流量本身。

## 建议继续看什么证据

- M1 订单量、M2 播放量两期对比：规模与流量的方向；
- M4 OPM、M5 GPM：交易效率有没有信号，是"没流量所以没订单"还是"有流量转化弱"；
- set_compare：在目录池中的相对位置，辅助判断当前水平；
- states：核对商品身份与跨期发布状态；当前标价可见但同一商品各期恒定，不能用来验证价格上涨；
- 素材条件、价格优势明细（如相对竞对平台的实时价差）、内容质量当前工具查不到，这些方向只能作为待验证假设列出，不能当作已核实的信号。

## 可考虑的经营方向

- 交易信号存在且效率稳定 → 可以考虑继续测试或尝试扩大供给，并设观察点；
- 只有规模问题（效率尚可）→ 先验证供给与曝光约束；
- 只有转化问题（流量已有）→ 转向吸引力与承接调查；
- 长期充分测试仍无有效信号 → 降低继续投入的优先级，但要先确认"测试充分"本身有证据；
- 素材 / 承接条件受限 → 先核对条件能否改善，再谈商品本身潜力。

## 分析边界

- 不做商品潜力评分，不写"满足几个条件就是潜力品"的伪公式；六类信号是检查清单，不是计分板；
- 具体案例中的价格带、素材数量不构成通用阈值；
- 目录池只是当前对比集合，潜力判断不引用行业水平。
