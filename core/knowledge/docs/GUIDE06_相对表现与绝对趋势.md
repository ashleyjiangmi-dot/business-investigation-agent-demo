# 相对表现与绝对趋势

## 适用问题

- 自己在下降，但还比商品池大多数商品好，该怎么看？
- 自己增长了，但还是低于同池商品，算好还是不好？
- 为什么不能只看排名？

## 怎么理解

回答"这个商品表现怎么样"，至少有两套互相独立的参照系，混用任何一套都会得出片面结论：

1. **自身跨期趋势**（时间维度）：这个商品自己是在变好还是变差。最基本的是两期对比的变化方向与幅度；数据域内有多期时，也可以逐期取值把窗口内走势连起来看——但那仍是**这段模拟窗口内**的走势，不是可外推的长期趋势。
2. **横向相对位置**（集合维度）：这个商品当前在对比集合里处于什么位置。看的是排名或与集合中位数的距离。
3. **可比性**（前提维度）：两期样本、覆盖、商品状态是否适合直接比较。这一条不是独立结论，而是前两条能不能成立的前提。

### 两个"反直觉"的组合

两套参照系独立，意味着四种组合都可能成立，其中两种最容易读错：

- **自身下降 + 相对仍领先**："当前水平仍较好"和"近期状态在恶化"同时成立。既不能因为排名还高就忽视下滑（趋势坏了不处理，位置迟早跟着坏），也不能因为下滑就否定它当前的价值（它仍比集合里大多数商品强）。通常的方向是：保住对当前水平的公允描述，同时把下滑原因查清。
- **自身增长 + 相对仍落后**："近期改善"和"当前竞争力仍弱"同时成立。改善方向正确不代表已经追平，增长速率好看不等于绝对水平可以接受。通常的方向是：确认改善能否延续，同时不因"在涨"就高估当前位置。

### 什么时候需要同时报告两个视角

- 经营判断类问题（值不值得继续投、要不要换动作）：通常两个视角都要，只报趋势或只报排名都不够；
- 单纯问"卖得怎么样"：至少给出绝对值与变化；
- 只有一个排名或只有一个单期值时，明确说明"还缺另一个视角"，而不是拿单一视角下经营结论。

### 对比集合本身要说清楚

排名与中位数都是相对"某个集合"而言的。Demo 的目录池只是**当前可对比的商品集合**，不等于行业大盘或市场基准。说"高于同品类"必须按实际类目筛选后比较，不假装全池就是同品类；说"领先"必须说明是相对哪个池的领先。

## 常见情况

- 商品下滑但排名靠前：先核对下滑幅度与全池变化——如果全池也在降，个体下滑的解释要收窄（全池共同下行不足以充分解释个体差异，但个体跌幅更大也只能支持有限判断，不能直接升格为个体特有的病因）；
- 商品增长但排名靠后：看增长的基数与绝对差距——低基数上的高增速常见，此时"增速"与"水平"要分开报告；
- 两期不可比（样本覆盖变化、窗口问题）：先处理可比性，趋势结论降级或悬置；
- 排名没变但两期值都降了：位置稳定不等于水平稳定，排名会掩盖共同下行。

## 建议继续看什么证据

- diff（两期对比）：自身趋势的方向与幅度，同时注意返回的百分比与绝对差；
- set_compare（同池中位数 / 排名）：横向位置，并确认对比集合是什么；
- 可比性信号：缺失与不可比会以 unknown 附原因码返回（如窗口不可比），样本覆盖变化只影响可比性与代表性判断——它解释"这次比较可不可靠"，但不能直接写成指标下降的原因；
- states / 单期取证：核对商品状态与数值口径；
- 结论里把"趋势"和"位置"分开表述，各配各的证据。

## 可考虑的经营方向

- 下降 + 领先 → 查下滑原因（供给 / 流量 / 转化 / 承接逐层核对），位置优势不处理下滑不可持续；
- 增长 + 落后 → 确认改善来自什么、能否延续，同时如实报告绝对差距；
- 需要两个视角时 → 同时报告绝对趋势与相对位置，并说明对比集合与可比性；
- 全池同步变化 → 先描述共同变化，个体结论收窄到有差异的部分。

## 分析边界

- 不引用行业平均水平或市场大盘数据——当前没有这类数据，目录池不构成行业基准；
- 不做没有数据支撑的市场趋势判断；
- 不用一个排名或一个单期值直接得出经营动作；动作需要趋势 + 位置 + 原因层的证据；
- 差异是否值得处理，需结合绝对规模、变化幅度与当前经营目标判断，不设统一阈值。
