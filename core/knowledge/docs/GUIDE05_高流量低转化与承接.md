# 高流量低转化与承接

## 适用问题

- 播放很多为什么不出单？
- 流量已经有了，还要不要继续补视频？
- 量已经跑出来了，用户却一直不下单，这种时候还该不该继续砸曝光？
- 内容表现不错但交易差，是价格问题还是门店承接问题？
- 本地生活为什么比普通内容业务更依赖 POI / 库存 / 券？

## 怎么理解

先给核心判断：**已经获得较多流量但交易效率弱时，继续单纯扩大曝光通常不能直接解决问题，应转向"商品吸引力 + 交易承接"调查。**

"流量高"只说明内容获得了分发，不等于商品已经具备交易竞争力。从播放到订单之间是一条更长的链条：内容曝光 → 用户产生兴趣 → 理解"为什么值得买" → 决定购买 → 线下承接（到店、核销）。链条上任何一环断了，最终都表现为"高流量、低转化"。所以高流量低转化不是一个原因，而是一族问题，需要逐环排查。

### 五类常见方向

1. **价格 / 优惠吸引力**：价格优势变化、券的价值感不足，都会影响交易意愿。但要注意，价格高低与转化弱之间不能直接画等号——是否构成问题，要看当前证据。
2. **卖点与用户需求匹配**：内容有人看，不代表用户理解了"为什么值得买"。内容结构里，卖点呈现、价格刺激、福利引导是各司其职的环节，任何一环表达失效都会让"看的人"变不成"买的人"。
3. **内容与商品匹配**：视频可能因为娱乐性或其他原因获得流量，但吸引来的用户并不是高购买意向人群——泛流量稀释转化效率，这种情况下播放越多、效率越难看。
4. **POI / 门店承接**：本地生活商品最终要落到真实门店和可核销场景。门店覆盖不足、位置或场景对不上，交易在最后一步流失。
5. **库存 / 券 / 履约条件**：内容侧一切正常，交易也可能在承接环节受限——券不可用、库存异常、核销条件苛刻，都会把已产生的购买意愿挡在门外。

本地生活与普通内容业务的差异就在第 4、5 环：它不是"内容看完即结束"，而是线上种草、线下履约的两段式交易。所以经营高流量低转化问题时，只看内容侧指标通常是不够的。

另一个常见误判需要指出：**内容表现好不代表交易一定能承接**。线上内容的点赞、播放、点击率，衡量的是内容对注意力的竞争力；订单衡量的是商品与承接对交易的竞争力。两套竞争力相关但不等价。

## 常见情况

- 播放靠前、OPM / GPM 偏低、内容侧无异常 → 典型的承接与吸引力问题形态，优先排查第 1、4、5 类方向；
- 流量高且转化曾经好、近期一起变差 → 先查当前工具可见的商品状态与发布变化；当前标价跨期恒定，价格上涨、券失效与其他承接变化在本数据域只能列为待验证假设，再谈内容；
- 播放高但点击率低 → 更像"内容吸引的是注意力不是购买意向"，匹配与卖点方向值得检查；
- 补了很多量、播放更多了、订单没变 → 这正是"扩大曝光不解决问题"的直接证据，应停止堆量转向承接调查。

## 建议继续看什么证据

- M4 OPM、M5 GPM 与 M1、M2 的组合：确认"流量高、效率弱"形态成立（先确认问题形态，再选方向）；
- states：商品身份与可见状态的跨期变化；标价可见但同一商品跨期恒定，不能核验价格回升；
- 两期 diff：效率是"一直弱"还是"在恶化"，两种形态对应的排查方向不同；
- set_compare：与目录池中位数 / 排名对照，区分"个体弱"和"全池都弱"；
- 单期取证：对关键数值做同源核对；
- 券详情、库存实况、门店服务质量、用户到店体验当前工具查不到——这些方向只能列为待验证假设，并明确说明无法核验的部分。

## 可考虑的经营方向

- 确认流量已充分且效率弱 → 停止单纯补量，转入承接与吸引力调查；
- 若另有价格变化证据 → 核对价格与交易变化的时间关系；当前模拟数据没有这一证据，不能把价格变化写成当前原因；
- 有可核对的承接异常信号 → 先调查承接，再评估内容动作；当前券 / 库存 / POI 无对应字段，只能列为待验证假设并如实说明；
- 点击率正常但下单弱 → 检查卖点表达与购买引导（作为待验证假设）；
- 所有方向都查不到证据 → 如实列出假设清单，不选一个冒充结论。

## 分析边界

- 不写"高流量低转化必须降价"；降价只是候选方向之一，且需要证据支持；
- 无数据时不断言"门店有问题""库存断了"是根因；承接类证据当前多数查不到，只能假设；
- 不虚构平台内部承接机制；本地生活"线上种草、线下履约"是公开的通用机制理解，具体平台规则不猜测。
