# 流量充足但承接不足

## 背景

这是一个用于说明分析方法的合成案例（synthetic case），不对应任何真实线上商品或真实运行数据。

场景设定：某个本地生活商品的短视频内容表现不错，已经获得了较多播放，播放量在商品池中处于靠前位置。但订单量和交易效率指标（OPM / GPM）表现弱，团队在讨论是不是再补一批视频。

## 观察到什么

- 播放量靠前：内容侧获得了明显更多的分发与观看；
- 交易效率弱：千次播放带来的订单与成交额低于同池水平；
- 内容侧没有明显异常：素材、发布节奏都正常。

（以上均为相对描述，本案例不使用也不虚构具体数值。）

## 可能解释

流量已经有了，问题不太可能出在"曝光不够"上。候选解释集中在"流量 → 交易"链条的中后段：

1. **价格 / 优惠吸引力不足**：价格优势变化或券的价值感不够，用户看了但不觉得值得买；
2. **卖点与购买引导缺失**：内容有人看，但没有传达清楚"为什么值得买"；
3. **内容与商品匹配偏差**：吸引来的用户不是高购买意向人群，泛流量稀释效率；
4. **POI / 门店承接不足**：本地消费最终落到门店，覆盖或场景对不上，交易在最后一步流失；
5. **库存 / 券 / 履约受限**：意愿产生了，但交易在承接环节被挡住。

## 如何继续区分

1. 先确认问题形态：流量充分 + 效率弱 + 内容侧正常——"继续补量"不解决问题，方向转向吸引力与承接；
2. 按当前可查证据排优先级：当前标价可见，但同一商品跨期恒定，不能据此验证“价格回升导致滑落”的假设；券、库存、门店服务、用户到店体验当前也查不到，列为待验证假设并如实说明；
3. 哪个方向有当前证据，就优先继续查哪个：例如属性有跨期变化，就核对变化与效率走弱的时间关系；
4. 都没有证据时：只能输出"待验证假设清单"，不挑一个顺眼的冒充结论，也不给确定性处方；
5. 若后续查明确有承接问题：先修承接，再评估内容与供给动作。

## 得到什么经验

**有流量但交易弱时，应从"获取更多流量"切换到"为什么现有流量没有完成交易"。**

流量解决"被看见"，承接解决"买得成"，两者是链条上不同的环节。已经获得较多流量还继续补量，通常只是放大低效。本地生活业务尤其如此：线上种草、线下履约两段式交易，只盯内容侧指标会漏掉承接环节的问题。

## 不能类比的条件

- 流量其实并不充足：应先按供给 / 流量问题处理（参见 CASE01 的形态），承接调查不是第一步；
- 效率弱伴随供给大幅下降：规模下降可能有更直接的供给解释，先排除；
- 有明确证据表明流量数据本身口径异常（如不可比窗口）：先处理数据问题再谈经营解释；
- 效率弱但全池同步走弱：先描述共同因素，个体承接结论要收窄。
