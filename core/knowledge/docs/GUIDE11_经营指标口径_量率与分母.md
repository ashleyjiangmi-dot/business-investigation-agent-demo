# 经营指标口径：量、率与它们的分母

## 适用问题

- OPM 变高了，是变好了还是只是播放量掉了？
- 订单量和播放量的口径一样吗？为什么一个是合计、一个要配对？
- 两个指标互相矛盾时，先看哪一个？

## 怎么理解

五个指标不在同一层，也**不在同一个分母上**。把"率"的改善当成"量"的改善，是把两层混成了一层。

### 五指标分层与口径

| 指标 | 含义 | 层 | 口径要点 |
|---|---|---|---|
| M1 订单量 | 该周期订单数 | 结果层 | 7 天口径**合计值，无分母** |
| M2 播放量 | 该周期播放量 | 流量层 | **所有行的 vv 求和，不做分发资格过滤** |
| M3 点击率 | 条均点击 | 内容层 | **条均口径**：分母=非缺失点击率行数，**不是曝光加权** |
| M4 OPM | 每千次播放订单数 | 效率层 | 只在**分发资格合格且播放与订单都存在的配对行**上算：Σ订单 ÷ Σ播放 × 1000 |
| M5 GPM | 每千次播放成交额 | 效率层 | 合格配对行上**按播放量加权**：Σ(单行 GPM × vv) ÷ Σvv |

三个最容易读错的点：

1. **M2 与 M4/M5 的行集不同**。播放量把所有行都算进去，效率指标只算合格且配对成功的行。所以"播放涨了但 OPM 的样本行少了"完全可能同时发生，此时两个数不能直接互推。
2. **M3 是条均，不是曝光加权**。它回答"平均每条内容的点击表现"，不回答"总流量里有多少被点击"。用 M3 与 M4 互相换算没有依据。
3. **M5 的加权方式**。它按播放量加权，等于让大流量行主导结果；与"各行取平均"不是同一个数。

### 模拟案例：识别通过率低，不等于交易效率低

设想内容经过投稿、商业内容识别、索引、分发、播放与交易。某类内容的识别通过率偏低，抽样发现普通随拍较多，与商业内容标准不匹配。

这里的比例是**识别通过内容数 / 投稿数**，只衡量前段识别。抽样与规则核对可以支持检查内容形态，却不能据此断言商品卖不动或应该降价。识别、分发与交易的分母不同；评估某一环节的调整，应先看该环节的通过量与后续可分发规模，不能把成交变化全部归因于识别。

当前数据域没有内容识别类型及各级通过数量。仅凭 OPM、GPM 或分发资格标记，无法确认识别折损。

### 率的分母会自己造出"变好"

率的分子分母同时变化。**播放量下降时，只要订单掉得慢，率就会上升**——这种"效率改善"不是经营改善。所以任何率的变化，都要同时看：分子方向、分母方向、参与行数。

率的改善只有在这三种形态下才是正向信号：量稳或涨、率涨；量涨、率小跌但绝对产出涨；量的结构变化被单独报告出来（例如泛流量增加）。

### 合计类与比率类的缺失不同

合计类（M1/M2）缺值表现为字段缺失或无记录；比率类（M3/M4/M5）还多一种**分母为零**。分母为零时返回 unknown 并附原因码，不静默代 0，也不回退成简单平均。三者的含义不同，不能统一说成"这个商品没有数据"。

## 常见情况

- **率升量降**：优先怀疑分母收缩，不要报"效率改善"；
- **量升率降、订单绝对值仍涨**：是规模扩张常见的稀释，要报告稀释而不是二选一；
- **M4 有值 M5 无值**：两者行集与加权方式不同，可能是成交额字段整体缺失或播放配对为 0，按原因码读；
- **两个商品 M4 相同**：不代表贡献相同，基数与行数可能差别很大（见 GUIDE13）。

## 建议继续看什么证据

- 每个指标返回块里的分母披露：`denominator`（类型、值与说明）、`n_rows` / `contributing_rows` / `eligible_rows` / `ineligible_rows` / `paired_rows`；
- `state` 与 `unknown_reason`：区分 period_missing / field_missing / zero_denominator / window_incomparable；
- 指标定义、单位与引用随查询下发；**读数以工具返回的口径说明为准**，不用记忆中的公式替代。

## 可考虑的经营方向

- 判断"变好/变差"时，先分层：结果层（M1）→ 流量层（M2）→ 效率层（M4/M5），并说明各层是否同向；
- 层间背离本身就是需要报告的发现，不是挑一个指标汇报的理由；
- 需要"效率"结论时，必须同时给出率的分子分母方向，否则只报数不报含义。

## 不能支持的判断

- 不能由 M3 推 M4，或由 M4 推 M5；三者行集与分母不同；
- 不能把率的上升自动写成"经营改善"，除非排除了分母收缩；
- 不能用单期一次峰值当作效率稳定的证据；
- 不得虚构数据域里没有的指标（核销率、毛利、退款、履约时长、内容质量分）——它们不在口径表内，问到即答"当前无该字段"。
