# 低流量商品经营

## 适用问题

- OPM / GPM 还可以，为什么就是不起量？
- 转化不错但播放量低，值得继续投内容吗？
- 低流量到底是商品问题还是内容问题？

## 怎么理解

核心框架：**低流量不等于低价值，要先看流量不足发生在什么条件下。**

OPM、GPM 这类效率指标是"每千次播放"的比率。比率不错但总量起不来，含义通常是"每一次曝光的质量还可以，但曝光次数不够"——问题在量的管道上，而不在质的环节上。这时该问的是：内容有没有被生产出来、有没有进入分发、分发后有没有获得曝光，而不是先怀疑商品吸引力。

理解流量从哪来，需要知道内容分发不是"发了就有量"的链路。真实业务里的本地内容分发是一条多级漏斗：投稿 → 内容识别 → 进入索引池 → 可分发 → 有分发 → 冷启出坡。每一级都有折损——内容可能因为识别环节没通过而进不了分发池，也可能进了池但没获得曝光。这条链路解释了一个常见现象：**"有内容"不等于"有流量"**，中间隔着好几道门。门在哪一关、为什么没过，才是低流量要排查的对象。

## 常见情况

低流量至少有以下几类可能方向，排查时逐个核对证据，而不是挑一个顺眼的解释：

1. **内容供给量不足**：发的量本来就少，测试机会没给够；
2. **新增投稿节奏下降**：历史上发得多、现在发得少，规模随供给收缩；
3. **商品仍处于早期测试阶段**：还没积累到足够曝光，属于"还没验证"而不是"验证失败"；
4. **分发资格 / 基础条件有问题**：内容没进入可分发状态，或 POI 等基础条件限制了分发；
5. **内容素材结构或开头表达不够有效**：内容获得了曝光机会但点击 / 停留弱——注意这类当前查不到数据，只能作为假设；
6. **商品本身热度有限**：类目或商品天然搜索与消费热度低，内容供给只能放大有限的需求。

### 三种典型组合

- **低流量 + 转化效率尚可**：更值得先验证"有没有扩大曝光的空间"。效率信号说明商品和内容在每次曝光上是能打的，限制在供给或分发环节——这是最值得继续投入的组合。
- **低流量 + 转化也弱**：不能仅靠扩大供给解决。先确认测试是否充分；测试充分而效率仍弱，问题在商品吸引力或承接上，堆量只会放大低效。
- **历史流量高、近期下降**：不按新品逻辑处理。先看供给变化（是不是发布少了）和商品状态变化（价格、承接有没有变），再判断是商品热度衰退还是经营动作缺位。

## 建议继续看什么证据

- M2 播放量两期对比（diff）：流量方向与幅度，区分"一直低"和"在下降"；
- M1、M4、M5：转化与效率是否同步走弱——效率还稳，优先查供给与曝光；效率同步弱，优先查吸引力与承接；
- published 状态（states）：当期是否还在新增发布，供给节奏有没有断；
- set_compare：播放量在目录池中的相对位置，区分"全池都低"和"个别低"——如果全池流量都在降，个体解释要谨慎（总体下行不足以充分解释个体差异，反过来个体差异也不能全推给个体原因）；
- 单期取证：对关键数值做同源核对；
- 分发资格、素材结构、开头表达、平台推荐机制当前工具查不到——这些方向只能写"值得检查"，不能宣布原因已经成立。

## 可考虑的经营方向

- 供给量或节奏不足 → 补足基础测试或恢复发布节奏，观察流量是否响应；
- 效率尚可且供给已恢复、流量仍低 → 列出分发资格与内容结构假设，说明当前无法核验的部分；
- 低流量且效率也弱 → 转向商品吸引力、价格、承接调查，不靠堆量解决；
- 历史高流量近期下降 → 先对齐供给与状态变化的时间线，再下判断；
- 全池同步走低 → 优先解释共同因素，个体结论收窄。

## 分析边界

- 不猜测平台算法黑箱；"分发链路存在多级折损"是机制层面的理解，具体为什么某个视频没获得分发，当前没有数据能回答；
- 不写"低 VV 就是开头差"这类单因断言——内容结构问题当前不可查，只能是假设；
- 不承诺某种内容优化一定提升流量；优化建议只能条件化表达（"若 X 有证据，则值得检查 Y"）；
- 流量与观察窗口以当前工具事实为准；本篇提供排查方法，不设“多少播放算不足”的固定标准。
