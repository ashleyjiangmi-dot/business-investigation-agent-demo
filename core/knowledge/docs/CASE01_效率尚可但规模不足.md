# 效率尚可但规模不足

## 背景

这是一个用于说明分析方法的合成案例（synthetic case），不对应任何真实线上商品或真实运行数据。

场景设定：某个本地生活商品已经进入观察阶段，历史上有过零星动销。最近两个周期里，它的交易效率指标（OPM / GPM）没有明显恶化，但订单规模一直上不来，团队在讨论还要不要继续给它投内容。

## 观察到什么

- 交易效率相对稳定：每次有曝光，转化表现没有明显走弱的迹象；
- 订单规模有限：绝对量小，增长乏力；
- 流量与新增内容供给都不足：播放量明显低于同池多数商品，当期新增发布也少。

（以上均为相对描述，本案例不使用也不虚构具体数值。）

## 可能解释

1. **商品吸引力差**——但与"效率尚可"的观察矛盾：如果商品本身不行，效率层通常也会走弱；
2. **供给与流量规模不足**——与观察一致：每次曝光的质量可以，但曝光次数太少；
3. **承接问题**——不完全吻合：承接断了通常连效率也保不住，此案例效率尚可，承接嫌疑靠后。

## 如何继续区分

先分清"效率层"和"规模层"两层信号，本案例效率层尚可，所以主查规模层的约束：

1. 查供给节奏：当期是否还在新增发布，供给是不是在收缩；
2. 查流量趋势：两期播放量的方向，是"一直低"还是"在下降"；
3. 查相对位置：播放量在商品池中处于什么位置，是个体低还是全池都低；
4. 若供给明显不足 → "补内容"成为候选动作，同时设观察点看流量与订单是否响应；
5. 若供给已经充分、流量机会给够但仍不起量 → 不能继续无限加量，转向分发资格、内容结构等假设，并明确哪些当前无法核验。

## 得到什么经验

**有效率信号但缺规模时，先验证曝光 / 供给约束；不要因为订单绝对量小就直接淘汰商品。**

效率是"质"的证据，规模是"量"的问题，两者要分开判断。绝对量小只说明"还没被足够多的人看见"，是否值得继续投入，取决于效率信号是否还在、供给约束是否真实存在。这类情况下，可先验证内容与供给节奏是否限制了曝光。

## 不能类比的条件

- 效率本身也在恶化：此时问题形态变成"质与量同时弱"，应先查商品吸引力与承接，而不是补量；
- 从未有过任何交易信号：应先按冷启动逻辑处理（确认基础测试机会），而不是按"有效率信号"的路径走；
- 两期数据不可比（样本覆盖变化、窗口问题）：先处理可比性，再套用本案例的判断顺序；
- 全池流量同步收缩：个体规模不足的解释要收窄，先看共同因素。
