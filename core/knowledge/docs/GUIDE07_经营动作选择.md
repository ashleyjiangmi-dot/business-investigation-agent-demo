# 经营动作选择

## 适用问题

- 现在应该补内容、继续观察、查价格还是降低投入？
- 多个指标同时变化时，怎么决定优先动作？
- 为什么两个"订单下降"的商品，可能应该采取不同动作？

## 怎么理解

经营动作不是从指标到动作的映射表，而是**针对不同问题形态的候选策略**。选动作之前，先回答一个前置问题：当前的限制在哪个环节——测试机会没给够（供给）、规模起不来（流量）、效率走弱（转化吸引力）、还是承接断了（履约）。环节定位不同，同一组指标对应的动作完全不同。

这就是为什么两个"订单下降"的商品可能需要相反的动作：一个下降伴随供给收缩，恢复供给是第一候选；另一个供给正常但效率恶化，补量只会放大低效。**先定位层，再选动作。**

### 五类动作与适用形态

**继续观察**

适合：商品仍处于早期测试；证据不足；关键数据缺失或两期不可比。
前置证据：确认"证据不足"是查证后的结论，而不是"还没去查"的借口——可查未查的部分要先查完，观察才成立。

**补内容 / 扩大供给**

适合：有交易效率或历史动销信号；当前主要限制更像供给 / 流量规模不足。
前置证据：效率层信号（OPM / GPM 尚可或有历史动销）+ 供给侧证据（发布收缩或供给不足）。两个条件都有的情况下，补供给才是"补短板"；只有前者没有后者时，先查供给为什么少。

**检查价格 / 商品 / 承接**

适合：已经获得一定流量；转化效率弱；或价格等商品属性出现异常信号。
前置证据：流量已具备 + 效率偏弱的组合形态；若提出承接属性跨期异常，还须有相应证据。方向见 GUIDE05。

**继续放大**

适合：已有稳定动销；内容与交易表现都提供正向信号；当前承接条件没有明显风险。
前置证据：效率稳定（不只一次峰值）+ 扩量后效率不稀释的观察点 + 承接核对。放大的同时要设观察点，不是放大完就不管。

**降低投入 / 降低优先级**

适合：已获得充分测试机会；长期没有有效动销或效率信号；继续增加同类供给的边际价值低。
前置证据：测试充分性本身要有证据（供给给够了、流量机会给够了、时间窗口够）。这是最需要证据支撑的动作——"降低投入"必须建立在"机会已给足"之上，而不是建立在失望情绪上。

### 多指标同时变化时

先把指标按层分组再看方向：

- 规模层（M1 订单量、M2 播放量）：回答"量"的问题；
- 效率层（M4 OPM、M5 GPM）：回答"质"的问题；
- 结合供给与状态证据（published、价格属性变化），看哪一层的信号与证据一致。

层与层方向不一致时（比如量在涨、效率在跌），通常说明结构在变（如泛流量增加），这本身就是需要报告的发现，而不是只挑好听的那个层汇报。

## 建议继续看什么证据

优先核对以下证据组合：

- 测试充分性：published 节奏 + 两期流量反馈 + 窗口可比性（决定"继续观察"还是"可以下判断"）；
- 效率信号：M4 / M5 两期 + set_compare 相对位置（决定"补内容"还是"查承接"）；
- 承接异常：先核对当前 `states` 实际返回的状态；价格跨期变化与券、库存、POI 异常在本数据域不能据此确认；
- 定位结论与动作之间：每个候选动作都应能说出"它针对哪一层的哪个证据"，说不出来的动作先挂着。

## 分析边界

- 候选动作的前提须有当前证据支持；不能把指标组合机械映射为固定动作；
- 经验知识不覆盖当前事实：知识说"通常值得查承接"，不等于当前商品承接有问题。
