# 集合比较的读数怎么读：所选集合、中位数、名次与并列

## 适用问题

- "高于同池中位数"这句话里的同池是谁选的？
- 排名并列时，名次说明了什么、没说明什么？
- 有的对象没有值，中位数还算不算数？
- 相对位置领先，能不能替代绝对水平？

## 怎么理解

**相对位置由本次选中的集合决定**。集合、参与对象、指标与并列规则都会改变结论。

### 集合是谁定的

集合比较只在**本次查询显式选中的对象**内计算，不会自动引入第三个集合。因此：

- "同池"="这次选进来的这批商品"，换一个选择结果就换一个基准；
- 集合比较返回自带基准披露，明确它是**同域相对位置，不是行业基准**；
- 说"高于同品类"必须先按品类把对象选出来，否则算的是全池位置。

### 中位数的三种分组

水平比较以所选集合该周期该指标的**中位数**为基准，分成高于 / 持平 / 低于三组：

- 没有值、或分母为零的对象**不参与比较**，会被单独列入缺失组；
- 因此中位数是"在可比对象里"的中位数。可比对象数与缺失对象数都要一起读，缺失多时基准的代表性就弱；
- 偶数个值时中位数取中间两数的平均，此时"恰好等于中位数"很少出现，持平组为空不代表没有并列。

### 名次不表示并列

名次排序在值相同时按**对象标识的稳定顺序**排开，不返回"并列第几名"。这带来两条读法约束：

- 相邻名次之间可能**数值完全相同**，名次差不代表水平差；
- 判断"是不是真的领先"要看数值与中位数组，而不是只看名次号；
- 需要并列信息时，用高于/持平/低于三组来表达，不要用名次号代替。

### 相对位置与绝对水平是两件事

位置领先说明"在这批对象里靠前"，不说明"水平本身可接受"。全集合体下移时，名次可以完全不变而所有对象的值都在降；反之亦然。经营结论应把"位置"与"水平/趋势"分开陈述（GUIDE06）。

## 常见情况

- 只有名次、没有中位数分组 → 不足以支撑"明显领先/落后"，需要补一次水平比较；
- 缺失组里有本次关心的对象 → 它的相对位置是缺失状态，不能被写成"低"或"差"（见 GUIDE14）；
- 所选集合很小（例如只选 3 个商品）→ 中位数由极少数对象决定，结论对集合构成敏感，应说明所选成员；
- 两个对象值相同、名次不同 → 并列的表现，不是水平差异；
- 指标换了（订单量 vs OPM）→ 同一集合的相对位置通常完全改变，比较必须绑定指标。

## 建议继续看什么证据

- 返回块里的集合信息：参与比较的对象清单、`usable_count`、`missing_count`、`missing_group`（含每个缺失对象的原因码）；
- `median` 与三个分组（高于 / 持平 / 低于）；
- `ranking` 的名次与数值成对读，不要只摘名次；
- `benchmark_disclosure` 与 `demo_caliber`：确认这是同域相对位置、Demo 口径；
- 品类与城市等身份信息：决定这次集合选得对不对（`catalog` 可查）；
- 行业大盘、竞品同池、历史分位：当前数据域没有，不能宣称。

## 可考虑的经营方向

- 报告相对位置时，同时交代集合构成与可比对象数；
- 需要"同品类对照"时，先按品类把对象选出来再比较，不拿全池冒充同品类；
- 位置与趋势结论冲突时（例如名次靠前但在下滑），两个视角都报告，不做取舍；
- 缺失对象进入比较之外，其位置结论改述为"不可比"。

## 不能支持的判断

- 不能把集合内领先说成"行业领先"或"市场平均水平以上"；
- 不能从名次差推导出水平差倍数；
- 不能把"持平组为空"读成"没有并列"；
- 不能用一次集合比较替代对当前值与变化的核对。
