# 内容供给策略

## 适用问题

- 这个商品该继续补视频，还是换内容方向？
- 有动销但投稿少，应该怎么理解？
- 已经发了不少内容还没有效果，是不是继续堆量？
- 为什么"素材多"不等于"有效内容供给充分"？

## 怎么理解

内容供给是本地生活商品的"测试与曝光管道"：商品要被看见、被测试、被验证，都要通过内容供给发生。所以判断供给问题，第一步永远是**先确认供给处在什么状态**，再谈动作。同一个"效果不好"，供给不足、供给下降、供给充分但无效三种状态下的解释和方向完全不同。

### 三类供给状态

**1. 内容供给不足**

特点：商品还没有获得足够的测试机会；投稿或新增内容明显不足；当前结果不足以否定商品。

经营方向：优先补足基础测试，而不是过早下结论。这时"效果不好"只能说明"还没验证出来"，不能说明"商品不行"。

**2. 供给下降 / 中断**

特点：历史有动销；当前订单或流量下降，同时伴随投稿 / 新增供给下降。

经营方向：先确认是不是供给缩减造成了规模下降，再判断商品本身是否变差。供给变化可能先于交易变化，但需要当前商品的跨期证据支持。

**3. 供给已经充分但效果弱**

特点：已经获得多轮内容与流量机会；仍然缺少有效交易信号，或效率持续偏弱。

经营方向：不应无限补量。继续加同类供给的边际价值低，应转向商品吸引力、价格、内容结构或承接条件的问题。

### 数量、质量与扩量条件

- **数量与质量不是同一个问题**。"内容数量"回答的是测试机会够不够；"内容质量 / 结构"回答的是单位内容有没有效率。数量补齐不能自动解决质量问题，反之亦然。
- **持续有动销且效率稳定的商品，更有理由尝试扩大供给**。这是追投逻辑的适用前提：先有稳定信号，再谈放大；放大后还要回来观察效率有没有被稀释。

### "素材多"不等于"供给充分"

供给应分三层看：内容供给层（发了多少、覆盖了多少商品）、流量表现层（有没有获得播放）、交易转化层（有没有带来动销和订单）。供给的"有效性"由后两层回答——发了很多但既没有播放也没有动销，说明供给没有形成有效触达，这本身就是一个需要解释的现象，而不是"已经充分供给"的证据。

## 常见情况

- **有动销但投稿少**：商品有交易信号，供给却没跟上——通常更值得补供给，而不是先怀疑商品；
- **发了不少内容还没有效果**：先核对流量反馈与测试充分性。若供给充分但既无播放也无动销，供给没有形成有效触达本身就是要解释的现象；若只有播放没有订单，问题大概率不在供给层；
- **有动销商品开始下滑、投稿同时在降**：优先核对供给收缩，并检查流量和效率是否同步变化；
- **低供给商品长期躺在池子里**：属于长尾激活范畴，用小批量测试探信号，而不是一次性大量供给；
- **供给在加、效率在跌**：数量补上了、质量或匹配没跟上——数量与质量问题要分开处理。

## 建议继续看什么证据

- published 状态（states 可查）：当期是否还有新增视频发布；供给是否在收缩或中断，通常先在这里出现信号；
- M2 播放量两期对比：供给变化之后流量有没有跟随；
- M1 订单量与 M4 / M5：交易信号与效率是否还在；
- diff（供给相关期次对比）：规模下降与供给下降是否同向发生；
- set_compare：供给与规模在目录池中的相对位置；
- 素材库存量、投稿条数、内容质量、券、库存与门店承接当前不可查；标价可见但同商品跨期恒定，不能验证价格变化。相关方向只能列为待验证假设。

## 可考虑的经营方向

- 供给不足 → 优先补足基础测试，不急着下商品结论；
- 供给下降伴随规模下降 → 先恢复供给节奏，观察规模是否回补；
- 供给充分但无有效信号 → 不再堆量，转向商品、价格、内容结构、承接条件调查；
- 有动销且效率稳定 → 可以考虑扩大供给，同时设观察点看效率是否稀释。

## 分析边界

- 不设统一的投稿条数标准；有效机会还取决于流量反馈与观察窗口（GUIDE09）；
- 发布状态只说明当期是否有新增发布，不能据此判断投稿条数或素材是否充足。
